# FP DROP

FP DROP is a student streetwear e-commerce concept for the Faculty of Business, Brno University of Technology. This repository contains the web prototype, a Python mobile-app simulator, and supporting project materials.

The shop, prices, stock, checkout, profile details, and editorial stories are demonstrations for an academic project. They do not represent an active store or real orders. VLOG items are editorial examples and should be replaced with approved contributions from real students before publication.

## Web prototype

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:3000/`). In Windows PowerShell, use `npm.cmd` if script execution blocks `npm`:

```powershell
npm.cmd install
npm.cmd run dev
```

To create a production build:

```bash
npm run build
```

Production preview of the build (serves `dist/` with SPA fallback, so `/blog/...` URLs work):

```bash
npm run preview
```

### Routes

Every main page has its own URL: `/`, `/shop`, `/drops`, `/lookbook`, `/news`, `/blog`, `/blog/<slug>`, `/about`, `/case-study`. The browser Back button and direct links work. Blog articles live in `src/data/blog.ts` (add a new object to `BLOG_POSTS` to publish another article).

### Product photos (Winter '26)

Product photos 20–43 are cut from the grid `assets/merch_grid_winter26.webp` into `public/products/winter26/` by:

```bash
pip install pillow numpy
python scripts/crop_merch_grid.py
```

The script detects the grid lines, removes the caption above each tile and centres the product on a 1000×1000 canvas. The mapping to products is in `src/data/productImages.ts`.

### SEO

`/robots.txt` and `/sitemap.xml` are generated by `seo.plugin.ts` (served in dev, written to `dist/` on build) from the routes and blog articles. Set `SITE_URL` in `.env` to the public address before deploying. Every page updates its `<title>`, meta description and Open Graph tags; unknown URLs show a 404 page marked `noindex`.

### Analytics (GA4 + Microsoft Clarity)

1. Copy `.env.example` to `.env` (PowerShell: `Copy-Item .env.example .env`).
2. Fill in `GA_MEASUREMENT_ID=G-XXXXXXXXXX` and `CLARITY_PROJECT_ID=xxxxxxxxxx`.
3. Restart `npm run dev`.

The Vite plugin in `analytics.plugin.ts` injects the official gtag.js and Clarity snippets into the `<head>` of every page, in dev (localhost) and in the production build. The app sends `page_view` on every URL change, `ui_click` for clicks on links and buttons, `scroll_depth` (25/50/75/90 %) and e-commerce/blog events (`view_item`, `add_to_cart`, `begin_checkout`, `blog_article_view`, …).

Options: `ANALYTICS_REQUIRE_CONSENT=true` shows the consent banner (GA4 Consent Mode v2 sends cookieless pings until the visitor accepts); `false` assumes consent (local testing only). `ANALYTICS_DEBUG=true` turns on GA4 `debug_mode` so events appear in GA4 → Admin → DebugView. Never commit `.env`.

## Python mobile prototype

The prototype is in `python_mobile_app/` and can run as a mobile-shaped web simulator using Python's standard library:

```bash
cd python_mobile_app
python main.py
```

It opens the simulator at `http://localhost:5050/`. An optional Flet version is also included; see `python_mobile_app/README.md` for its setup.

## Main folders

- `src/` — React, TypeScript, and Vite website
- `public/` and `product-assets/` — web and product images
- `python_mobile_app/` — Python mobile simulator and optional Flet app
- `assets/academic/` — project presentation visuals
- `scripts/` — project asset and document generation utilities
